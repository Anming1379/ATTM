# 07 · 构建与发布

> 从 `git clone` 到能双击运行的安装包。
>
> 相关文件：`ATTM.csproj`、`tools/publish.ps1`、`packaging/ATTM.iss`、`assets/install-dotnet.cmd`、`app.manifest`。

---

## 1. 环境要求

| 项 | 要求 | 说明 |
| --- | --- | --- |
| SDK | **.NET 10 SDK** | `net10.0-windows` + `UseWPF` |
| 操作系统 | Windows 10 / 11 x64 | WPF 与 winmm 都是 Windows 专有 |
| 打包（可选） | Inno Setup 6 | 只有生成安装包时需要；装在任意盘都能被自动找到 |
| 发布（可选） | Python 3 + Pillow | 只有重新生成图标时需要（`tools/make-icon.py`） |

---

## 2. 工程文件要点

```xml
<TargetFramework>net10.0-windows</TargetFramework>
<UseWPF>true</UseWPF>
<Nullable>enable</Nullable>
<ImplicitUsings>enable</ImplicitUsings>
<Version>0.2.1</Version>
<LangVersion>latest</LangVersion>
<SatelliteResourceLanguages>zh-Hans;en</SatelliteResourceLanguages>

<!-- 测试工程有自己的 csproj，源码不参与主程序编译 -->
<Compile Remove="tests\**" />
<None Remove="tests\**" />
<Page Remove="tests\**" />
<Resource Remove="tests\**" />

<!-- 字体与图标编译进程序集 -->
<Resource Include="assets\fonts\*.ttf" />
<Resource Include="assets\icon.ico" />
```

> **版本号只有一个真相源**：`ATTM.csproj` 里的 `<Version>`。`publish.ps1` 用正则从 csproj 读它，安装包文件名、`AppVersion` 定义都由它派生。改版本只改这一处。

## 3. 构建

```bash
dotnet build                      # 调试构建
dotnet run --project ATTM.csproj  # 直接运行

dotnet build -c Release           # 发布配置
```

产物在 `bin/Debug/net10.0-windows/` 或 `bin/Release/net10.0-windows/`。

## 4. 测试

```bash
dotnet run --project tests/ATTM.Tests        # 语法 / MIDI / 播放 / 文件 / 配置
dotnet run --project tests/ATTM.UiChecks     # 进程内 VisualTree + 位图渲染检查
dotnet run --project tests/ATTM.UiChecks -- --dump out.png   # 顺便导出界面截图
```

退出码 **0 = 全绿**。两套都是零依赖控制台断言，不需要 xUnit/NUnit。详见《08-测试体系》。

## 5. 发布脚本 `tools/publish.ps1`

### 5.1 用法

```powershell
# 默认：框架依赖 + zip + 安装包
powershell -ExecutionPolicy Bypass -File tools\publish.ps1

# 自包含（拷走就能跑，不用装 .NET）
powershell -ExecutionPolicy Bypass -File tools\publish.ps1 -SelfContained

# 只出 zip，不调 Inno Setup
powershell -ExecutionPolicy Bypass -File tools\publish.ps1 -SkipInstaller
```

### 5.2 参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `-Configuration` | `Release` | 构建配置 |
| `-Runtime` | `win-x64` | RID |
| `-Output` | `dist` | 输出根目录 |
| `-SelfContained` | 关 | 自包含单文件（约 60 MB） |
| `-SkipInstaller` | 关 | 跳过 Inno Setup |

### 5.3 脚本做了什么

1. 从 `ATTM.csproj` 正则读 `<Version>`。
2. 清空并重建 `dist/app`。
3. `dotnet publish`（单文件、无符号）：

```text
dotnet publish ATTM.csproj -c Release -r win-x64 -o dist/app
  -p:DebugType=none -p:DebugSymbols=false
  -p:SatelliteResourceLanguages=zh-Hans
  -p:PublishSingleFile=true
  [--self-contained true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true]
  [--self-contained false]
```

4. 复制文档：`README.md`、`ATTM 语法教程.md`、`LICENSING.md`、`THIRD-PARTY-NOTICES.md`、`AI-GENERATED-NOTICE.md`、`LICENSE`。
5. 复制 `assets/install-dotnet.cmd` 与 `install-dotnet.ps1`。
6. 递归复制 `samples/`。
7. `Compress-Archive` 出 `dist/ATTM-<版本>-win-x64.zip`。
8. 调 Inno Setup 出 `dist/installer/ATTM-<版本>-setup.exe`。

### 5.4 Inno Setup 的定位逻辑

`Find-InnoCompiler` 依次尝试：

```text
1. 注册表 Uninstall\Inno Setup 6_is1 的 InstallLocation（HKLM / WOW6432Node / HKCU）
2. %ProgramFiles%\Inno Setup 6\ISCC.exe
3. %ProgramFiles(x86)%\Inno Setup 6\ISCC.exe
4. %LOCALAPPDATA%\Programs\Inno Setup 6\ISCC.exe
5. 硬编码 D:\Program Files (x86)\... 与 D:\Program Files\...
6. PATH 里的 ISCC.exe
```

找不到就打印提示并**跳过安装包**（zip 仍然产出），不报错退出。

### 5.5 产物体积参考（框架依赖）

| 文件 | 体积 | 备注 |
| --- | --- | --- |
| `dist/app/ATTM.exe` | ~1.7 MB | 需要 .NET 10 桌面运行时 |
| `dist/ATTM-<版本>-win-x64.zip` | ~0.8 MB | 绿色版 |
| `dist/installer/ATTM-<版本>-setup.exe` | ~2.6 MB | 安装包，会自动装运行时 |

自包含时 `ATTM.exe` 约 60 MB，安装包约 55 MB。

## 6. 安装包行为（`packaging/ATTM.iss`）

### 6.1 基本信息

| 项 | 值 |
| --- | --- |
| AppId | `{7C4E1B62-9D3A-4F7E-8A11-2B5C6D7E8F90}` |
| AppName | ATTM |
| 默认目录 | `{autopf}\ATTM` |
| 压缩 | `lzma2/ultra64` + solid |
| 权限 | `PrivilegesRequired=lowest`，可用命令行/dialog 覆盖 |
| 架构 | `x64compatible`，64 位模式安装 |
| 最低系统 | `MinVersion=10.0` |
| 语言 | 简体中文 + English |

### 6.2 任务（可勾选）

- `desktopicon`：桌面快捷方式（**默认不勾**）。
- `associate`：关联 `.attm` 谱面文件（**默认勾选**）。

### 6.3 文件关联

```text
HKA\Software\Classes\.attm                              = "ATTM.Score"
HKA\Software\Classes\ATTM.Score                          = "ATTM 谱面"
HKA\Software\Classes\ATTM.Score\DefaultIcon              = "{app}\ATTM.exe,0"
HKA\Software\Classes\ATTM.Score\shell\open\command      = ""{app}\ATTM.exe"" ""%1"""
```

`HKA` 会按权限自动落到 `HKCR`（管理员安装）或 `HKCU\Software\Classes`（普通用户安装）。

### 6.4 示例谱子安装位置

```text
{code:GetMusicFolder}\ATTM\欢乐颂 - 演示谱.attm
{code:GetMusicFolder}\ATTM\小星星 - 演示谱.attm
{code:GetMusicFolder}\ATTM\Affix Your Name! - Anming_cat.attm
{code:GetMusicFolder}\ATTM\ATTM 语法教程.md
```

全部带 `onlyifdoesntexist` + `uninsneveruninstall`：**不覆盖用户改过的文件，卸载也不删**。

`GetMusicFolder` 依次读：`Shell Folders\My Music` → `User Shell Folders\My Music` → `%USERPROFILE%\Music`。用户把音乐目录重定向到别的盘也能正确落地。

### 6.5 运行时依赖检查

安装时执行（静默、等待完成）：

```text
{app}\install-dotnet.cmd /quiet
Check: NeedsDotNet
```

`NeedsDotNet()` 扫描 `{commonpf}\dotnet\shared\Microsoft.WindowsDesktop.App`，只要存在以 `10.` 开头的子目录就跳过安装；否则调用安装助手（约 60 MB，需要联网）。

### 6.6 快捷方式

- 开始菜单：`ATTM`、`ATTM 谱面示例`、`安装 .NET 10 运行时`、`卸载 ATTM`
- 桌面：`ATTM`（仅当勾了 desktopicon）

## 7. 应用清单 `app.manifest`

```xml
<requestedExecutionLevel level="asInvoker" uiAccess="false" />   <!-- 从不请求管理员 -->
<dpiAware>true/pm</dpiAware>
<dpiAwareness>PerMonitorV2</dpiAwareness>                      <!-- 多显示器 DPI 正确 -->
<longPathAware>true</longPathAware>
```

`PerMonitorV2` 对自绘编辑器尤其重要：DPI 变化会触发 `SizeChanged` → `UpdateMetrics()` 重算字宽与行高。

## 8. 图标

```bash
python tools/make-icon.py        # assets/icon-source.png -> assets/icon.ico（多尺寸）
```

`icon.ico` 被 csproj 以 `<Resource>` 方式嵌入并设为 `ApplicationIcon`，同时被安装包用作 `SetupIconFile`。

## 9. 发布检查清单

1. 改 `ATTM.csproj` 的 `<Version>`。
2. 更新 `README.md` 里下载链接的文件名（`ATTM-<版本>-setup.exe`）。
3. 更新 `PLAN.md` 的进度小节。
4. 跑两套测试，确认退出码 0。
5. `powershell -File tools\publish.ps1`。
6. 手动验收：装 → 双击 `.attm` 能打开 → 播放出声 → 保存产出 `.attm` + `.mid` → 卸载干净。
7. 上传 `dist/installer/*.exe` 与 `dist/*.zip` 到 Releases。
