# 08 · 测试体系

> 两套**零依赖**控制台断言 harness。没有 xUnit、没有 NUnit、没有 Moq。
> 退出码 **0 = 全部通过**，非 0 = 有失败。

| 工程 | 行数 | 覆盖 | 需要 UI 线程 |
| --- | --- | --- | --- |
| `tests/ATTM.Tests` | ~1 500 | 词法 / 语法 / 时值 / MIDI / 播放 / 缓冲 / 高亮 / 配置 / 文件编码 / 性能 / MIDI 导入（99 项） | 否 |
| `tests/ATTM.UiChecks` | ~1 170 | 进程内 VisualTree、真实渲染像素、主题色值、动画时序、交互流程（49 项） | 是（STA） |

---

## 1. 运行方式

```bash
dotnet run --project tests/ATTM.Tests
dotnet run --project tests/ATTM.UiChecks
dotnet run --project tests/ATTM.UiChecks -- --dump out.png   # 额外导出界面截图
```

CI 里只看退出码即可。

> 注意：`dotnet run ... | head` 拿到的是**管道最后一个命令**的退出码，会掩盖失败。脚本里要么 `set -o pipefail`，要么不加管道。

临时文件统一写到 `AppContext.BaseDirectory/tmp`（harness 里的 `TempRoot`），不依赖系统 `%TEMP%`——受限环境里 `%TEMP%` 可能没有写权限，会导致整组文件相关断言假失败。

## 2. `ATTM.Tests` 覆盖面

### 2.1 词法

- 注释行；`#4` 是升号而不是注释；每个数字字符单独成 token；行尾注释。

### 2.2 指令

- `bpm` 支持小数；`bpm = 120` 报 E3（等号后缺空格）；缺少 bpm 报 E1；缺少调式报 E2；
- 调式必须 A–G（E110）；只支持 4/4 与 3/4（E111）；重复声明（E4）；出现在小节之后（E5）；
- `Vel` 解析与默认值 `90 +-0`；越界报 E109。

### 2.3 时值

- `1` 是全音符；`1,0` 被休止截断为半音符；`1,0,0,0` 为四分音符；
- `3,3,4,5`、`11,12,3,05`、`1134,5,12,0057`、`3,02,2,0` 的逐音 tick 断言。

### 2.4 和弦与多声部

- `(46+1),(57+2),(357),(6+1+3)`；反拍 `0(46+1),…`；组内音共享源码区间；
- 三行同时演奏；空行分隔两个小节；注释行不打断小节组；同音高重叠被覆盖。

### 2.5 3/4 与错误形态

- 3/4 下 `1,2,3`、`1,2`、`1,2,3,4` 合法；4/4 下 2 个逗号报 E108；
- E107 非 2 的幂、E114 空段与行尾逗号、E104 未闭合、E105 空和弦、E106 和弦内 0、E101 数字 8、E117 八度标记后无数字。

### 2.6 八度与音高

- `++1` 合法；`+-1` 报 E102；
- `1 = D` / `1 = B` 下的 `1` / `+1` / `-1` / `#7` 映射；超出范围报 E115；
- `1 = #C` 与 `1 = C#` 等价；升号调式再加 `#` 是双重升号。

### 2.7 位置与容错

- 偏移与行列互换；语法错误时仍能拿到部分乐谱。

### 2.8 MIDI

- 导出后**回读一致**（用 `tests/ATTM.Tests/MidiReader.cs` 反向解析 SMF）；
- 文件头为 PPQ 480 / 120 BPM / 4-4；3/4 拍号写入正确；力度抖动被限制在 1–127。

### 2.9 播放（`PlaybackChecks.cs`）

用**假时钟 + 记录型输出**离线验证：起播位置、暂停/续播的音重发、停止后 All Notes Off、到达时长触发 Finished、`GetActiveSpans` 的高亮区间。

### 2.10 缓冲与高亮

- `TextBuffer` 的插入与行列映射、跨行删除；
- 高亮：注释 / 指令 / 音符 / 休止 / 升降号分类正确；行号与源码行一一对应。

### 2.11 主题与配置

- 配置字符串与枚举映射；Light 配置不会被判成深色；默认字号已放大到 18。

### 2.12 文件

- UTF-8 无 BOM + LF 往返；BOM 与 GBK 老文件都能读；默认保存目录是 `音乐\ATTM`；保存同时产出 `.attm` 与 `.mid`；谱库目录固定。

### 2.13 文档一致性（重要）

- **把《ATTM 语法教程》里的示例谱面全部解析一遍**（五分钟上手、八度叠加、三种等价时值、八分十六分、升降号、三和弦、反拍和弦、多声部、注释不打断分组、3/4、升号调式、力度抖动、小数 bpm）。
- **把 README 里的示例谱面全部解析一遍**。
- 解析 `samples/` 下的所有 `.attm`。

> 这组测试的价值：语法改了但文档没改，测试直接红。改语法时请顺手改文档，否则过不了。

### 2.14 性能

- 2000 行谱面解析 < 1 秒。

## 3. `ATTM.UiChecks` 覆盖面

在**进程内**创建真实的 `MainWindow`，走真实布局与渲染，然后用 `RenderTargetBitmap` 抽样像素。

### 3.1 基础渲染

- 窗口已渲染（尺寸合理）；深色调色板已应用（背景 == `#FF141417`）；
- 图标字形已渲染；**Lekton 与 Material Symbols 字形真实存在**（不只是字体名匹配）；
- 编辑器控件已挂载；编辑器**绘制出真实文字像素**；语法高亮真实渲染；插入符颜色出现；行号槽已绘制；缩略图已绘制在右侧；编辑器不显示滚动条。

### 3.2 交互流程

- 输入后文本长度增加、解析出新小节；撤销恢复文本；重做恢复输入；插入非法内容后状态栏报错；
- 「新建文档默认载入《小星星》示例」；
- 播放按钮启用 → 点击进入播放 → 编辑器有高亮 → 停止回到就绪；
- 工具栏有「从光标处播放」按钮；
- 命令行参数能打开 `.attm`（模拟双击关联）；不存在的参数回退到新建模板；
- 保存对话框预览双文件路径；
- 设置窗口能渲染并列出 MIDI 设备；**设置改动立即生效（没有保存按钮）**。

### 3.3 缩略图

- 缩略图与内容对齐（用 `YForLine` / `ViewportTop` 等公开映射取样）；长文档不会糊成一片。

### 3.4 乐句预览

- 工具栏有切换按钮；展开在缩略图右侧；并行声部的每一行都显示；
- 换句时文字从行外滑入；新句立即入场、旧句渐隐；小节结束前提前退场；
- 沿用编辑器的语法配色；大字排版不重叠不裁切；
- **动画帧只重绘不重排**（`LayoutBuildCount` 在动画期间不增长）；
- 播放时自动跟随当前小节；实时框出正在播放的音；再次点击收起。

### 3.5 主题

- 浅色调色板切换成功（背景 == `#FFF7F7F9`）；主题色为 `#FFFF4E6A`；浅色下仍能绘制文字。

### 3.6 大文件

- 两千行仍能流畅渲染。

## 4. 断言 harness 的写法

两套程序都是同一个极简模式：

```csharp
var passed = 0;
var failed = 0;

void Check(string name, Func<bool> body, string? detail = null)
{
    try
    {
        var ok = body();
        // 打印 [OK] / [FAIL] name（失败时附 detail）
    }
    catch (Exception ex) { /* 记为失败并打印异常 */ }
}

Environment.ExitCode = failed == 0 ? 0 : 1;
```

特点：

- **一个 Check 一个场景**，名字就是断言内容（中文，直接可读）。
- 失败时打印实际值与期望值（例如 `背景 #FF1C1C21`）。
- 不需要 [Test] 标记，只要新增一行 Check(...) 就注册了一条测试。

新增测试的最小步骤：

```csharp
Check("我的新规则：xxx 应该是 yyy", () =>
{
    var r = AttmParser.Parse("bpm = 120\n1 = C 4/4\n\n1,2,3,4");
    return r.Notes.Count == 4 && r.Notes[0].StartTicks == 0;
});
```

## 5. 为什么不用 xUnit

| 理由 | 说明 |
| --- | --- |
| 零依赖 | 与项目「零第三方 NuGet」原则一致 |
| 能跑 WPF | UiChecks 需要在 STA 线程里起真实窗口，测试框架反而增加复杂度 |
| 输出可读 | 中文断言名 + 实际值，失败时一眼看出哪里错 |
| 启动快 | `dotnet run` 几百毫秒，适合每轮改动都跑 |

代价：没有 fixtures、没有并行、没有覆盖率统计。对本项目规模是划算的。
