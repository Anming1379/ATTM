# 04 · 编辑器实现

> ATTM 的编辑器不是 TextBox，也不是 AvalonEdit，而是从 `FrameworkElement` 手写的。
> 本文说明它为什么这样长、每一层负责什么、坑在哪里。
>
> 相关文件：`Editing/` 下 8 个文件，约 2 700 行。

---

## 1. 为什么自绘

需求同时要求四件 AvalonEdit / RichTextBox 都做不好的事：

| 需求 | TextBox 的问题 | AvalonEdit 的问题 |
| --- | --- | --- |
| 可见行虚拟化（2000 行要顺滑） | 版式不定 | 可以做，但要引入 3 万行依赖 |
| 简谱语义高亮（音符/休止/八度/指令分色） | 做不到 | 要写自定义高亮器 |
| 按**源码区间**做播放高亮 | 完全做不到 | 要写自定义着色器 |
| 精确字符宽度（侧边栏与缩略图共用同一度量） | 拿不到 | 要反射进内部 |

自绘的代价是 `1092` 行的 `EditorTextView`，换来的是全部可控 + 零依赖。

## 2. 控件树

```text
AttmEditor : Grid                          <- 宿主，4 列
 ├─ EditorGutter   (col 0, width 54)       <- 行号 + 错误圆点（不接收鼠标）
 ├─ ScrollViewer    (col 1, 滚动条隐藏)
 │   └─ EditorTextView                     <- 真正画字与收键盘的控件
 ├─ EditorMinimap   (col 2, width 80)      <- 整篇缩略图 + 视野框，点击/拖动跳转
 └─ Border          (col 3, width 0<->460) <- 乐句预览容器，宽度做动画
     └─ PhrasePreview
```

**滚动条故意隐藏**：导航完全交给缩略图；`Shift + 滚轮` 做横向滚动（`AttmEditor` 的 `PreviewMouseWheel`）。

---

## 3. 文本缓冲 `TextBuffer`

```text
_text         : string    // 全文，行分隔统一为 LF
_lines[]      : string[]  // 每行内容
_lineStarts[] : int[]     // 每行首字符偏移
Version       : int       // 每次内容变化 +1
```

- `Replace(offset, removeLength, insertText)`：拼接后**全量** `Rebuild()`。
- 行列互转都是二分查找（`GetLineColumn` / `GetOffset`）。
- **`Version` 是缩略图的缓存钥匙**：TextBuffer 原地修改，引用不变不代表内容不变。

为什么不用 rope / piece table：谱面上限几千行，全量重建索引是微秒级；rope 的复杂度会渗进每一个调用点。

## 4. 渲染（`EditorTextView.OnRender`）

绘制顺序（后画的盖住先画的）：

```text
1. 背景矩形
2. 当前行底色             DrawCurrentLine
3. 选区                   DrawSelection
4. 播放高亮               DrawPlayback
5. 每行文字（FormattedText）
6. 错误波浪线             DrawDiagnostics
7. 插入符 / IME 组合串     DrawCaret
```

### 4.1 度量

```text
_charWidth  = width of "M" in the editor typeface
_lineHeight = round(fontSize * 1.38)
TextPaddingLeft = 12, TextPaddingTop = 8
```

`MeasureOverride` 把整个文档的尺寸报给 ScrollViewer（宽 = 最长行 × 字宽，高 = 行数 × 行高），于是滚动能落到正确位置；而 `OnRender` 只画可见行。

### 4.2 可见行虚拟化

```text
first = max(0, floor((verticalOffset - paddingTop) / lineHeight))
last  = min(lineCount-1, floor((verticalOffset + viewportHeight - paddingTop) / lineHeight) + 1)
```

`verticalOffset` / `viewportHeight` 从祖先 ScrollViewer 拿（`Loaded` 时向上找一次并缓存）。

### 4.3 FormattedText 缓存

`Dictionary<int, FormattedText> _lineCache`，上限 **400** 行，超出整体清空。高亮区间在构建缓存时一次性上色；**选区与播放高亮不进缓存**（随交互变化，直接画矩形）。

### 4.4 列转像素：`MeasureColumn(line, column)`

取该行前 `column` 个字符造一个临时 FormattedText，返回宽度。这是自绘编辑器最贵的一次调用：

| 场景 | 优化 |
| --- | --- |
| 命中测试 `HitTestColumn` | 对列做**二分**，O(log n) 次测量 |
| 选区/高亮/插入符 | 每帧每行最多 2 次测量 |

### 4.5 错误波浪线

`DrawWavy`：以 3 px 步长在 y±1.8 之间往复的 StreamGeometry，笔宽 1.2，画在行底 −3 px。区间来自 `Diagnostic.Span` 减去行首偏移。

### 4.6 播放高亮

`_playbackSpans` 是 SourceSpan 数组（一套区间可能跨多行）。逐 span 换算行列区间，限定在可见行内画半透明矩形，宽度至少 3 px 保证单字符可见。

`SetPlaybackSpans` 做了**相等性短路**：内容一致就不重绘，避免播放时每 10 ms 重画一次。

## 5. 输入

### 5.1 键盘（`OnPreviewKeyDown`）

| 键 | 行为 |
| --- | --- |
| Ctrl+Z / Ctrl+Y / Ctrl+R | 撤销 / 重做 |
| Ctrl+A / C / X / V | 全选 / 复制 / 剪切 / 粘贴 |
| Ctrl+Home / Ctrl+End | 文首 / 文末 |
| Backspace / Delete | 删字符（**代理对感知**：UTF-16 高低代理一次删 2 个 char） |
| Enter / Tab | 插入换行 / 插入 4 个空格 |
| 方向键 / Home / End / PageUp / PageDown | 光标移动，Shift 扩展选区 |
| Escape | 取消选区 |

**垂直移动保留目标列**：`_preferredColumn` 记录起始列，跨过短行后回到长行列号不丢。

### 5.2 文本输入与输入法

- `OnTextInput` 处理普通字符（过滤回车、换行、ESC）。
- 输入法走 `TextCompositionManager.AddPreviewTextInputStartHandler / UpdateHandler`，组合串存进 `_compositionText`，在**插入符位置**用前景色绘制，下方画 1 px 主题色下划线表示「正在组合」。
- 失焦或提交时清空组合串。

> 已知限制：候选框窗口由系统 IME 决定，自绘控件无法控制其坐标。

### 5.3 鼠标

| 操作 | 行为 |
| --- | --- |
| 单击 | 定位光标并进入拖选（CaptureMouse） |
| 双击 | 选中「词」——连续的字母数字或 # + - _ |
| 三击 | 选中整行 |
| 拖动 | 实时按命中位置更新 caret（anchor 不动） |
| Ctrl + 滚轮 | 字号 ±1（范围 9–40） |

命中测试：y 直接算行号；x 走 `HitTestColumn` 二分，落在字符中点右侧取后一列。

## 6. 撤销 / 重做

```csharp
readonly record struct EditCommand(int Offset, string Inserted, string Removed);
```

- 栈上限 **200** 步，超出从底部丢。
- 新编辑发生时清空 redo 栈。
- **合并启发式**：
  - 连续输入：上一条是纯插入、位置相接、双方都不含换行、合并后 ≤ 120 字符 → 合并成一条。
  - 连续退格：同理，从后往前合并。
- Undo / Redo 复用 `ApplyEdit(..., record: false)`，不污染栈。

## 7. 行号槽 `EditorGutter`

`FrameworkElement`，宽 54，`IsHitTestVisible = false`（不抢鼠标）。

- 只画可见行（与文本区共用 LineHeight / TopPadding / VerticalOffset）。
- 当前行数字用亮色，其余用暗色。
- 错误行在左侧 x = 11 画半径 2.6 的红点。
- 字体是编辑器字体降 3 px（最小 10），右对齐到 `ActualWidth - 12`。

## 8. 缩略图 `EditorMinimap`

### 8.1 统一映射（核心）

```text
_linePixel = clamp((height - 2*TopMargin) / lineCount, 0.05, 6.0)
YForLine(line) = TopMargin + line * _linePixel
```

**条、视野框、光标标记全部用这一个映射**。历史上「缩略图与内容错位」就是三者各算一套坐标导致的，改成统一映射后彻底解决（并有 UiChecks 断言）。

### 8.2 分桶画条

```text
linesPerBucket = max(1, ceil(MinBucketPixel / _linePixel))   // MinBucketPixel = 4
bucketPixel    = linesPerBucket * _linePixel
barHeight      = max(1.2, bucketPixel * 0.58)
barWidth       = clamp(usableWidth * 平均行长/最长行, 6, usableWidth)
```

桶内**没有任何非空行就留空**，所以空行形成的段落间隙在缩略图上看得出来。

### 8.3 配色优先级

```text
有错误行        -> Error（红）
含等号的指令行   -> Directive（蓝）
整桶都是注释     -> Comment（灰）
其它            -> Note（前景色）
```

所有颜色都经过 `Soft(source, alpha, desaturate)`：降饱和 + 压低透明度，做成淡淡的文字影子，不抢正文注意力。

### 8.4 缓存与交互

- 内容层是 DrawingGroup，仅在 buffer 引用变 / Version 变 / 行高变 / 配色变 / 错误行集合变 / 尺寸变 时重建。
- 点击或拖动：把 y 反解成行，以视野中心对齐后回调 `ScrollRequested`。
- 悬停画一条 2 px 的提示横线。

## 9. 乐句预览 `PhrasePreview`

工具栏第 4 个按钮（ToggleButton）展开，宽 460，显示**当前播放小节的那几行**（并行声部都在），用超大字号。

### 9.1 内容来源

`AttmEditor.BuildPhraseLines(measureIndex)`：

```text
first = MeasureStartLines[index]
last  = 下一小节首行 - 1，或最后一行
逐行：跳过空行与纯注释行；去掉行首缩进，并把高亮区间整体左移
产出 PhraseLine(Text, Runs, Offset = 行首偏移 + 缩进)
```

### 9.2 排版只做一次

`PhraseLayout.Build` 计算：字号（14–64 自适应，取不超宽不超高的最大值）、每行 FormattedText、每行左右偏移、裁剪矩形、最宽行宽度。

**动画帧内只做 PushTransform + DrawText**，不重排版——`LayoutBuildCount` 在动画期间不得增长（有测试断言）。

### 9.3 入退场

| 阶段 | 时长 | 表现 |
| --- | --- | --- |
| 入场 | 240 ms | 逐行错开 60 ms，从行外滑入 40 px + 淡入，缓出曲线 EnterCurve |
| 出场 | 85 ms | **纯渐隐**，不位移；起点透明度上限 0.5 |

换句时新旧**叠着交替**：旧句立刻压暗并渐隐，新句立刻入场，屏幕上永远有可读内容。

此外 `FadeOutPhrase()` 会在小节结束前 **160 ms**（`MainWindow.PhraseFadeLeadSeconds`）就让旧句开始退场，`_fadedMeasure` 保证同一小节不重复触发。

### 9.4 实时高亮

`SetActiveSpans(spans)` 把播放中的源码区间换算成「第几行的第几列到第几列」，画主题色框。

### 9.5 侧边栏宽度动画

`AttmEditor.AnimatePhraseWidth` 用**自己驱动的 DispatcherTimer（16 ms，三次缓出）**，220 ms 完成；没走 WPF 动画，因为离屏/虚拟显示环境里动画时钟可能不推进，无头测试就跑不完。

展开时 `MainWindow.EnsurePhraseRoom` 把 MinWidth 提到 **1180**（收起回 720），窗口不够宽会主动撑宽。

## 10. 配色 `EditorPalette`

从主题资源解析 22 个 Brush，每项都有硬编码回退（主题字典缺键也不会崩）：

```text
背景 / 前景 / 当前行 / 选区 / 播放高亮 / 插入符
行号槽背景 / 行号文字 / 当前行号文字 / 边框
错误 / 错误柔色 / 强调色
注释 / 指令 / 值 / 音符 / 升八度 / 降八度 / 升号 / 标点 / 休止
```

`BrushFor(EditorTokenClass)` 做映射；Unknown 落到错误色（不认识的东西标红）。

## 11. 数据流小结

```text
用户按键
  -> EditorTextView.ApplyEdit
  -> TextBuffer.Replace + Version++
  -> BufferChanged（AttmEditor 转发）
  -> MainWindow.MarkDirty / ScheduleParse
  -> [180 ms] Reparse -> AttmParser.Parse
  -> Editor.ApplyParse(ParseResult)
       -> EditorHighlighter.Build -> 配色区间
       -> 诊断按行分组（波浪线）
       -> EditorGutter.ErrorLines
       -> EditorMinimap.Update
```

## 12. 改编辑器的注意事项

1. **任何改 FormattedText 的地方都要清 `_lineCache`**，否则显示旧颜色。
2. **新增一种高亮类别**要同时改：`EditorTokenClass`、`EditorHighlighter.Classify`、`EditorPalette`（新增 Brush）、两个 Palette XAML、`BrushFor`。
3. **不要在 OnRender 里做排版**；乐句预览已经把这条规则写成测试。
4. **动画不要依赖 WPF 动画时钟**，用 DispatcherTimer 自驱动，否则无头测试跑不动。
5. 改了绘制行为记得跑 `dotnet run --project tests/ATTM.UiChecks`，它会做像素级抽查。
