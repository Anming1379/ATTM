> 本文是 `Core/Syntax` 的**权威描述**，与 `ATTM 语法教程.md` 的分工是：
> 教程面向写谱的人（例子多、循序渐进），本文面向改解析器的人（规则精确、边界明确、含诊断码全表）。

---

## 1. 核心术语

| 术语 | 英文/类型 | 定义 |
| --- | --- | --- |
| **小节** | measure | 由**空行**分隔的一段。4/4 一小节 = 1920 tick，3/4 = 1440 tick |
| **声部** | voice line | 小节的每一行。连续多行（中间不空行）属**同一个小节**，同时发声 |
| **段** | segment | 一行按逗号切开的每一块。段数决定每段多长 |
| **单元** | unit | 段内一个独立时值单位。可以是一个音、一个休止 `0`、一个和弦 `(…)`、一个 `legato(…)` |
| **音级** | degree | 简谱数字 1–7 |

---

## 2. 词法（`AttmLexer`）

逐字符扫描，输出 `List<Token>`。**每个数字字符单独成一个 `Number` token**（`"11"` 是两个音，不是十一）。

| 输入 | Token | 说明 |
| --- | --- | --- |
| `\r\n` / `\r` / `\n` | `NewLine`（文本统一为 `"\n"`） | CRLF 合并成一个 |
| 空格 / `\t` / `U+3000` 全角空格 | `Whitespace` | 连续合并 |
| `0`–`9` | `Number` | **单字符** |
| `#` + 紧跟数字 | `Sharp` | 升降号 |
| `#` + 处于调式声明位置 | `Sharp` | `1 = #C 4/4`、`1 = C# 4/4` |
| 其它 `#` | `Comment` | 吃到行尾 |
| `.` `+` `-` `,` `(` `)` `/` `=` `$` `%` | 对应符号 token | `$`→`LineOctaveUp`，`%`→`LineOctaveDown` |
| ASCII 字母 / `_` | `Identifier` | 连续合并；`bpm`、`Vel`、`legato`、`C`–`G` 都走这里 |
| 其它（含中文） | `Unknown` | 解析阶段报 `E102` |

### 2.1 `#` 的歧义消解规则

`#` 有两种角色，判定顺序（`IsKeySharpMarker`）：

1. 后面紧跟 ASCII 数字 → **升号**（`#4`）。
2. 前一个有效 token 是 `Equals`，且后一个字符是 `A`–`G` 范围内的字母 → **调号升号**（`1 = #C`）。
3. 前一个有效 token 是单个 `A`–`G` 的 `Identifier`，且再往前是 `Equals` → **调号升号**（`1 = C#`）。
4. 其余 → **注释**。

「有效 token」= 跳过空白，遇到换行即终止（不会跨行判断）。

> 副作用（有意为之）：`1,2 # 说明`、`#注释`、`# 注释` 全部是注释，写谱时不必担心 `#` 被误判。

## 3. 行分类

每个物理行先做一次分类（`Parser.Run`）：

| 行内容 | 处理 |
| --- | --- |
| 只有空白/换行 | **空行** → `FlushGroup()`，当前小节组结束 |
| 只有注释 | 注释行 → **不打断分组**（不执行 `FlushGroup`） |
| 指令行 | `bpm` / `Vel` / `1 = …` → `ParseDirective` |
| 其它 | 谱面行 → 剥掉行首 `$`/`%` 前缀后加入当前小节组 |

**指令行判定**（`IsDirectiveLine`）：
- 第一个有效 token 是 `Identifier` 且忽略大小写等于 `bpm` 或 `vel`；或
- 第一个有效 token 是 `Number` 且文本为 `"1"`，第二个是 `Equals`。

## 4. 指令

三条指令，**必须写在第一个小节之前**（否则 `E5`），**每条只能出现一次**（否则 `E4`），**等号右侧必须有空格**（否则 `E3`）。

### 4.1 `bpm = 数值`

```text
bpm = 120
bpm = 92.5
```

- 支持整数与小数（token 拼接后 `double.TryParse`，`InvariantCulture`）。
- 取值范围 **[1, 1000]**，越界 `E112`。
- 等号右侧必须一路到行尾都是数字，否则 `E3`。

### 4.2 `1 = 根音 拍号`

```text
1 = C 4/4
1 = G 3/4
1 = #F 4/4      # 升号前置
1 = F# 4/4      # 升号后置
```

- 根音：`C D E F G A B`（大小写不敏感），其它字母 `E110`。
- 升号：前置（`#C`）或后置（`C#`）均可，二者等价。
- 两个都写（`1 = #C#`）**不会**得到「双升」：后置的那个 `#` 不满足调号升号判定，会退化成注释起点，随后因为缺拍号报 `E3`。升号调只写一个。
- 拍号：只接受 **4/4** 和 **3/4**，其它 `E111`；格式不对（缺 `/`、缺数字、后面有多余内容）报 `E3`。
- 根音与拍号都必须存在，缺任一报 `E3`。

### 4.3 `Vel = 基准 [+-抖动]`

```text
Vel = 90
Vel = 90 +-10
```

- 基准：整数 **[1, 127]**，越界 `E109`；非整数 `E3`。
- 抖动：`+-` 后面跟整数 **[0, 127]**，越界 `E109`；格式（比如写成 `+10` 或 `+ -10`）错 `E3`。
- 省略时默认 **90 +-0**。
- 抖动在**生成 MIDI 消息时**才逐音随机（`MidiSequence.ApplyJitter`），解析期只记录数值。

## 5. 小节分组

- 连续的非空行 = 同一小节的多个声部，按**出现顺序**编号 `VoiceIndex = 0,1,2…`。
- 每个小节组结束时 `_measureIndex++`，并把组首行记录到 `MeasureStartLines`。
- 文件结束时若还有未 flush 的组，会补 flush。
- 一组里如果所有行都被 `$`/`%` 前缀剥空了（`body.Count == 0`），该行直接跳过。

---

## 6. 行八度前缀 `$` / `%`

```text
$ 1,2,3,4       # 整行升一个八度
$$ 1,2,3,4      # 升两个八度
% 1,2,3,4       # 降一个八度
```

规则（`ReadLinePrefix`）：

| 情况 | 结果 |
| --- | --- |
| 行首连续 `$`/`%` | 计数，`shift = ups - downs`，只作用于该行所有音 |
| `$` 与 `%` 混用 | `E119`，且 **shift 归零**（该行按原八度演奏） |
| 前缀后没有空格 | `E120`（例如 `$1,2,3`） |
| `$`/`%` 出现在行中 | `E118`（只报一次，仍按已读到的前缀处理） |

前缀对整行生效，**包括 `legato(…)` 里的音**。

## 7. 行结构：段与单元

一行先按**逗号**切成段（`ParseVoiceLine`）：

```text
1,2,3,4          → 4 段，每段 1 个单元
11,12,3,05       → 4 段，单元数 2/2/1/2
(46+1),(357)     → 2 段，每段 1 个和弦单元
```

### 7.1 段数约束

| 拍号 | 允许段数 | 等价说法 |
| --- | --- | --- |
| 4/4 | 1 / 2 / 4 | 0 个、1 个、3 个逗号 |
| 3/4 | 1 / 2 / 3 / 4 | 最多 3 个逗号 |

不符 → `E108`。
**空段**（`1,,` 或行尾逗号）→ `E114`，该行剩余部分不解析。

### 7.2 单元数约束

每个段里的单元个数必须是 **2 的幂**：1、2、4、8……，否则 `E107`。
（`legato(…)` 的括号内「拍位数」也遵守此规则，**休止 `0` 计入**。）

## 8. 时值算法（关键）

设 `M = MeasureTicks`（4/4 = 1920，3/4 = 1440），段数 `S`，第 `s` 段有 `U_s` 个单元。

```text
segmentTicks = M / S
unitStart(u, s) = s*segmentTicks + round(segmentTicks * u / U_s)
unitEnd(u, s)   = s*segmentTicks + round(segmentTicks * (u+1) / U_s)
segmentEnd(s)   = round(M * (s+1) / S)
duration(i)     = start(i+1) - start(i)      # i 为整行扁平序列里的下一个单元
最后一个单元     → duration = M - start(i)
```

三条推论（就是用户手册里那三句话）：

1. **一个音响到下一个单元开始**；行内最后一个音响到小节末尾。
2. **`0` 会截断前一个音**，因为 `0` 占了一个单元位置，把下一个 start 提前了。
3. **时值不足 15 tick**（`MinUnitTicks = 480/32`）报 `E113`。

### 例子：`3,02,2,0`（4/4）

```text
S=4, segmentTicks=480
段0 "3"     : unit(0/1) start=0    end=480
段1 "02"    : unit(0/2) start=480  end=720    ← 休止，无声
              unit(1/2) start=720  end=960    ← "2"
段2 "2"     : unit(0/1) start=960  end=1440
段3 "0"     : unit(0/1) start=1440 end=1920   ← 休止
扁平序列: [0:3] [480:0] [720:2] [960:2] [1440:0]
→ 3 从 0 响到 480（480 tick = 1 拍）
→ 2 从 720 响到 960（240 tick = 半拍）
→ 2 从 960 响到 1440（480 tick = 1 拍）
```

### 例子：`1134,5,12,0057`

段 0 有 4 个单元 → 每个 120 tick（八分音符）；段 2 有 2 个单元 → 每个 240 tick；段 3 有 4 个单元 → 每个 120 tick。

## 9. 音符

```text
[+|-]* [#] digit
```

解析顺序（`TryParseNote`）：

1. **八度标记**：重复读 `+`/`-`，每个累计 ±1 八度。
   - 混用（`+-1`）→ `E102`，且该标记不计入。
   - 标记后面必须**紧邻**下一个 token（中间不能有空格）→ 否则 `E117`。
2. **升号** `#`：必须紧贴数字，否则 `E103`。
3. **数字**：
   - `0` → 休止。若同时带了 `+`/`-`/`#` → `E101`（仍按休止处理）。
   - `1`–`7` → 正常音。
   - `8`/`9` → `E101`。
   - 没有数字 → `E102`「无法识别的音符」。

### 9.1 音高映射（`PitchMapper`）

```text
pitch = 60 + rootOffset + (keySharp ? 1 : 0)
      + MajorScale[degree-1]        # {0,2,4,5,7,9,11}
      + octave * 12
      + (sharp ? 1 : 0)
```

- `rootOffset`：C=0 D=2 E=4 F=5 G=7 A=9 B=11。
- **`1 = C` 时主音是中央 C（MIDI 60）**。
- `octave` 是「行前缀 shift + 所有 `+`/`-`」的合计。
- 结果必须在 **[0, 127]**，否则 `E115`。

| 写法（`1 = C`） | 音名 | MIDI |
| --- | --- | --- |
| `-1` | C3 | 48 |
| `1` | C4 | 60 |
| `+1` | C5 | 72 |
| `++1` | C6 | 84 |
| `#1` | C#4 | 61 |
| `+#4` | F#5 | 78 |
| `7` | B4 | 71 |

## 10. 和弦 `( … )`

```text
(46+1)           # C 大三和弦（C4 E4 G4）
(357)            # 三音同时
0(46+1)          # 反拍：和弦前面先放一个休止单元
```

- 括号内所有音**共享同一 start / duration / 源码区间**。
- 括号内不能有休止 `0` → `E106`（仍会跳过该音继续）。
- 括号内为空 → `E105`（跳过整个括号继续）。
- 括号未闭合 → `E104`，该段停止解析。
- 括号不嵌套（内层 `(` 会终止外层的查找）。

---

## 11. 连奏 `legato( … )`

```text
legato(1234)             # 四个音依次起音，每个都撑到本段末尾
legato(1020)             # 0 也占一个拍位，不发声
$ legato(1357)           # 与行前缀连用（前缀作用于括号内的音）
```

语义（`ParseVoiceLine` 的 `IsLegato` 分支）：

```text
noteStart(n) = unitStart + round(unitTicks * n / N)
noteEnd(n)   = min(max(noteStart+1, segmentEnd), measureTicks)
```

也就是说：**依次起音，但每个音都延音到本段末尾**，形成真正的 legato（后音叠在前音尾巴上，直到段末统一收音）。

约束：

| 情况 | 诊断码 |
| --- | --- |
| `legato` 后没有紧跟 `(` | `E121` |
| 括号为空 | `E122` |
| 括号内用逗号 | `E124` |
| 括号内嵌套 `(` | `E124` |
| 括号未闭合 | `E104` |
| 括号内拍位数不是 2 的幂 | `E107` |

## 12. 同音高重叠（`NoteMerger`）

解析完所有 `NoteEvent` 后统一处理：

1. 按 `Pitch → StartTicks → VoiceIndex` 排序。
2. 后出现的音若与「上一个同音高音」**时间重叠**：
   - 后音起点 ≤ 前音起点 → 直接**移除前音**；
   - 否则 → 把前音**截断**到后音起点。
3. 结果按 `StartTicks → Pitch` 输出。

作用：多声部写和弦时重复的音不会被触发两次，MIDI 里也不会出现悬空的 NoteOn。

## 13. 诊断码全表

`DiagnosticCode` 是**稳定数值**（文档与测试都引用它）。所有诊断的 `Severity` 目前都是 `Error`。

### 13.1 结构与指令（1–5）

| 码 | 枚举名 | 触发条件 | 消息 |
| --- | --- | --- | --- |
| 1 | `MissingBpm` | 全文没有 `bpm` 指令 | 缺少 bpm 声明，例如 "bpm = 120" |
| 2 | `MissingKeySignature` | 全文没有调式/拍号 | 缺少调式与拍号声明，例如 "1 = C 4/4" |
| 3 | `DirectiveSyntax` | 缺等号、等号后无空格、值格式错、拍号格式错 | 视具体位置而定（见源码分支） |
| 4 | `DuplicateDirective` | 同一指令出现两次 | "bpm" 只能声明一次 / 调式与拍号只能声明一次 / "Vel" 只能声明一次 |
| 5 | `DirectiveAfterContent` | 指令出现在小节之后 | 指令必须写在所有小节之前 |

### 13.2 词法 / 音符 / 结构（101–120）

| 码 | 枚举名 | 触发条件 | 消息 |
| --- | --- | --- | --- |
| 101 | `InvalidDigit` | 数字是 8/9；或休止 `0` 带了升降号/八度 | 只允许数字 1 到 7（0 表示休止）/ 休止符 0 不能带升降号或八度标记 |
| 102 | `InvalidCharacter` | 无法识别的音符；`+` 与 `-` 混用 | 无法识别的音符 / 八度标记不能混用 + 和 - |
| 103 | `SharpWithoutDigit` | `#` 后没有紧邻数字 | 升号 # 后面必须紧跟数字 |
| 104 | `UnclosedParenthesis` | 和弦 / legato 括号未闭合 | 和弦括号没有闭合 / legato 括号没有闭合 |
| 105 | `EmptyChord` | `()` | 和弦括号内不能为空 |
| 106 | `RestInChord` | `(0…)` | 和弦括号内不能使用休止符 0 |
| 107 | `UnitCountNotPowerOfTwo` | 段内单元数不是 2 的幂 | 同一个节拍段里的音符个数必须是 1、2、4、8…… |
| 108 | `InvalidSegmentCount` | 段数不符合拍号 | 4/4 拍每行只能有 0、1 或 3 个逗号 / 3/4 拍每行最多 3 个逗号 |
| 109 | `VelocityOutOfRange` | `Vel` 基准或抖动越界 | 力度基准必须在 1 到 127 之间 / 随机力度范围必须在 0 到 127 之间 |
| 110 | `InvalidKeyRoot` | 根音不在 C–G | 调式必须是 C、D、E、F、G、A、B（可加 #，例如 1 = #C 4/4） |
| 111 | `InvalidTimeSignature` | 拍号不是 4/4 / 3/4 | 仅支持 4/4 和 3/4 拍 |
| 112 | `BpmOutOfRange` | `bpm` 不在 [1, 1000] | bpm 必须在 1 到 1000 之间 |
| 113 | `UnitTooShort` | 单元时值 < 15 tick | 音符时值过短（小于三十二分之一拍） |
| 114 | `EmptySegment` | 逗号前后没内容 / 行尾逗号 | 空的节拍段：逗号前后必须有音符或休止符 |
| 115 | `PitchOutOfRange` | 映射后超出 [0,127] | 音高超出 MIDI 范围（0 到 127） |
| 116 | `EmptyMeasure` | **已定义，当前解析器未使用** | — |
| 117 | `OctaveMarkerWithoutDigit` | `+`/`-` 后不是紧邻的数字 | 八度标记 +/- 后面必须紧跟数字 |
| 118 | `LineOctaveNotAtStart` | `$`/`%` 出现在行中 | 八度前缀 $ / % 只能写在行首，例如 "$ 1,2,3,4" |
| 119 | `LineOctaveMixed` | 同一行混用 `$` 和 `%` | 八度前缀不能混用 $ 和 % |
| 120 | `LineOctaveWithoutSpace` | 前缀后缺空格 | 八度前缀 $ / % 后面必须跟一个空格，例如 "$ 1,2,3,4" |
| 121 | `LegatoSyntax` | `legato` 后没有 `(` | legato 后面必须紧跟括号，例如 "legato(1234)" |
| 122 | `LegatoEmpty` | `legato()` | legato 括号内不能为空 |
| 123 | `LegatoRest` | **已定义，当前解析器未使用**（`0` 在 legato 内是合法拍位） | — |
| 124 | `LegatoNested` | legato 内出现逗号或嵌套括号 | legato 括号内不能再用和弦括号 / legato 括号内不能用逗号 |

### 13.3 诊断对象结构

```csharp
sealed record Diagnostic(
    DiagnosticCode Code,
    DiagnosticSeverity Severity,   // Warning | Error（当前只用 Error）
    string Message,
    int Line,                      // 1 起
    int Column,                    // 1 起
    SourceSpan Span);              // 字符偏移 + 长度，用于波浪线
```

**排序**：`Span.Start` 升序，同偏移按 `Code` 升序（`Parser.Run` 末尾）。

## 14. 容错策略

| 场景 | 行为 |
| --- | --- |
| 某一段解析失败 | `return` 掉整行，该行不产生音符；诊断已记录 |
| 某个括号为空 | 跳过该括号，**继续**解析同行剩余内容 |
| 数字非法 | 跳过一个 token，继续 |
| 指令重复 | 保留第一次的数值，报 `E4` |
| 指令位置错误 | 忽略该行，报 `E5` |
| `Score` 是否生成 | 只有 `bpm` + 调式 + 拍号**三者齐全**时才生成 `Score`（允许同时存在其它错误） |
| 能否播放/保存 | `ParseResult.CanPlay = Score != null && ErrorCount == 0` |

2. 新增诊断 → `DiagnosticCode`（**只追加，不改已有数值**）+ 解析分支 + 本文第 13 节表格。
3. 改时值算法 → 同时更新 `tests/ATTM.Tests` 里对应断言与本文第 8 节。

   ```bash
   dotnet run --project tests/ATTM.Tests
   dotnet run --project tests/ATTM.UiChecks
   ```
